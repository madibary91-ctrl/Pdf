# jalali-date (لایهٔ ۱ · خالص · 🔴 بازبینی انسانی)

**هدف:** تبدیل و محاسبهٔ تاریخ جلالی/میلادی، قالب‌دهی، تجزیه و محاسبهٔ مواعد — بدون I/O.

**وابستگی:** فقط `shared-types`.
**دامنهٔ پشتیبانی‌شده:** سال ۱۲۰۰ تا ۱۶۰۰ جلالی (خارج از آن `OUT_OF_RANGE`).

## رابط عمومی (`index.ts`)
| تابع | توضیح |
|---|---|
| `validateJalaliDate` / `validateGregorianDate` | اعتبارسنجی؛ ۳۰ اسفند فقط در سال کبیسه |
| `jalaliToGregorian` / `gregorianToJalali` | تبدیل دوطرفه |
| `jalaliToEpochDay` / `epochDayToJalali` | شمارهٔ روز از ۱۹۷۰ (برای محاسبات) |
| `jalaliFromInstant(date, tz='Asia/Tehran')` | تاریخ جلالیِ یک لحظه؛ ساعت را بیرون می‌دهند |
| `isJalaliLeapYear`, `jalaliMonthLength` | کبیسه و طول ماه |
| `addDays`, `addMonths`, `addYears`, `diffInDays` | حساب تاریخ (`clamp` یا `reject` برای روزِ ناموجود) |
| `weekdayIndex`, `isFriday` | ۰ = شنبه … ۶ = جمعه |
| `formatJalaliDate`, `parseJalaliDate` | قالب‌دهی؛ تجزیه با ارقام فارسی/عربی/لاتین و جداکننده‌های `/ - .` |
| `computeDeadline` | مهلت روزی/ماهی/سالی با گام‌های شرح‌داده‌شده |

همهٔ توابعِ شکست‌پذیر `Result` برمی‌گردانند، نه `throw`.

## تصمیم‌های مهم
- **سال دورقمی پذیرفته نمی‌شود** (ابهام قرن؛ خطای تاریخ پرهزینه است).
- **`addMonths`:** پیش‌فرض `clamp`؛ ۳۱ شهریور + ۱ ماه = ۳۰ مهر.
- **`computeDeadline` فرضِ حقوقی ندارد:** شمردن یا نشمردن روز ابلاغ و انتقال به روز کاری گزینه‌اند، نه قانون. هر کاربرد باید با حقوقدان مالک کیفیت تأیید شود.
- **تعطیلات رسمی در این ماژول نیست.** داده‌ای نسخه‌دار است و باید از بیرون (`isNonWorkingDay`) تزریق شود. پیش‌فرض فقط جمعه.

## اعتبار الگوریتم
تست‌ها: نمونه‌های مرجع (نوروزها، ۲۲ بهمن ۱۳۵۷)، رفت‌وبرگشت و پیوستگیِ **همهٔ روزهای ۱۲۰۰–۱۶۰۰**، و هم‌خوانی با `Intl` سیستم در ۱۳۰۰–۱۴۵۰.
⚠ بازبین انسانی باید سال‌های کبیسهٔ آینده (پس از ۱۴۷۰) را با تقویم رسمی مرکز تقویم مؤسسهٔ ژئوفیزیک مقایسه کند؛ الگوریتم حسابی است، نه نجومی.

## خارج از این ماژول
تعطیلات رسمی، یادآوری، نمایش تقویم در رابط (`ui-rtl`)، مواعد قانونیِ خاص هر دادخواست (`legal-calc`).
