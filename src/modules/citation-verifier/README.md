# citation-verifier (لایهٔ ۳ · خالص · 🔴 بازبینی حقوقدان)

**هدف:** «ارجاع نامعتبر هرگز خروجی نمی‌شود.» هر ارجاعی که مدل (یا کاربر) به یک ماده/تبصره/بند می‌دهد، با پایگاه دانش و **در تاریخِ مورد نظر** سنجیده می‌شود و فقط حکمِ `accepted: true` اجازهٔ نمایش دارد. بدون I/O و بدون ساعت (تاریخ از بیرون می‌آید).
**وابستگی:** فقط `legal-kb-schema` و `shared-types` (طبق `registry.ts`).

> ⚠️ **این ماژول هیچ قانون یا ماده‌ای ندارد و هیچ نام قانونی در کدش نیست.** نام‌ها و متن‌ها فقط از Corpus ورودی می‌آیند؛ تست‌ها با نمونهٔ **ساختگی** و Corpusهای تصادفی کار می‌کنند.
> در `registry.ts` وضعیتش «done» است (تأیید مالک معماری؛ ناحیهٔ پرریسک است و هر تغییر بعدی همچنان بازبینی انسانی می‌خواهد). طراحی و دلیل‌ها: `docs/adr/0011-citation-verifier.md`.

## دو لایهٔ دفاع

| لایه | تابع | کار |
|---|---|---|
| **۱ — ارجاع ساختاریافته** (اصلی) | `verifyCitation(index, claim, isoDate, policy?)` · `verifyCitations(index, claims, isoDate, policy?)` | حکم بسته برای هر ادعا؛ نقل‌قولِ اختیاری هم سنجیده می‌شود |
| **۲ — متن آزاد** (خط دوم) | `checkText(index, text, isoDate, options?)` · `redactRejected(text, check, marker?)` | ارجاع‌های درون متن را پیدا، راستی‌آزمایی و (در صورت نیاز) حذف می‌کند |

مدل باید ارجاع ساختاریافته بدهد (لایهٔ ۱). لایهٔ ۲ برای ارجاع‌هایی است که در متنِ پاسخ نشت می‌کنند.

## حکم‌ها (`VerdictCode`؛ فهرست بسته)

| کد | معنا | `accepted` |
|---|---|---|
| `valid` | هست، در تاریخ معتبر است، تأییدشدهٔ حقوقدان است، نقل‌قول (اگر هست) درست است | ✅ |
| `unverified-source` | همه‌چیز هست ولی هنوز حقوقدان تأیید نکرده | ❌ (فقط با `allowUnverified: true`، برای ابزار داخلی) |
| `unknown-document` · `unknown-article` · `unknown-subpart` | در پایگاه نیست | ❌ |
| `not-yet-in-force` · `no-longer-in-force` · `gap` | در آن روز معتبر نیست | ❌ |
| `quote-mismatch` | نقل‌قول در متن همان ماده/بخش (در همان نسخه) نیست یا بیش‌ازحد کوتاه است | ❌ |
| `malformed` | شکل ارجاع/تاریخ/نقل‌قول نامعتبر | ❌ |

هر حکمِ رسیده به یک نسخهٔ واقعی، `evidence` (سند، ماده، بازهٔ اعتبار، بخش، `verified`) دارد.

## نقل‌قول

`claim.quote` (اختیاری) باید **واژه‌به‌واژه** در متن همان نسخهٔ معتبر باشد: ارجاع به تبصره/بند ⇒ فقط متن همان بخش؛ ارجاع به ماده ⇒ متن ماده یا بخش‌های **همان نسخه** (نه ماده‌ای دیگر). «…» یا `...` بخش‌ها را جدا می‌کند (به‌ترتیب، بی‌هم‌پوشانی). هم‌سان‌سازی فقط نگارش است (ارقام، «ي/ك»، اعراب، نیم‌فاصله و نشانه‌گذاری مرز واژه‌اند)؛ نقل‌قول کوتاه‌تر از `MIN_QUOTE_CHARS` رد می‌شود (برشِ «و» همه‌جا هست).

## متن آزاد: دستور زبان و شکست‌به‌سمت‌ایمنی

می‌فهمد: `[تبصره|بند <برچسب>] (ماده|اصل) <عدد> [مکرر [n]] | ماده واحده  [از] <نام سند>`؛ ارقام فارسی/عربی/لاتین. نام سند = عنوان، عنوان بی‌بخش‌های پرانتزی یا `shortTitle` یکی از سندهای Corpus (بلندترین نام برنده است). **هر چیزِ ارجاع‌گونه که نتواند به یک سند+ماده یکتا نسبت یابد رد می‌شود، نه نادیده:**

| وضعیت | مثال | نتیجه |
|---|---|---|
| `no-document` | «ماده ۱۰» بی‌نام قانون | رد (مگر `defaultDocumentId`) |
| `unknown-document` | «ماده ۱۰ قانون X» که X در Corpus نیست | رد |
| `ambiguous-document` | نامی که به دو سند می‌خورد | رد |
| `malformed` | «ماده ۰»، «مکرر ۱»، برچسب تبصرهٔ نامعتبر | رد |
| `unsupported-form` | «مواد ۲ و ۳»، «تبصره ماده ۲» | رد |

`redactRejected` فقط ارجاع‌های ردشده را با `DEFAULT_REDACTION` (که خودش ارجاع نیست) عوض می‌کند؛ اگر نتیجهٔ بررسی به آن متن تعلق نداشته باشد `Result` خطا می‌دهد.

### محدودیت‌های شناخته‌شده (صادقانه)
عدد حروفی («ماده ده»)، «همین قانون»، ارجاعِ سند‌-نخست («در قانون X ماده ۲») و «تبصره/بند» بی‌ماده **تشخیص داده نمی‌شوند**؛ لایهٔ ۲ جایگزین ارجاع ساختاریافته نیست. هدفِ حذف‌شده‌ها (مثل «مدنی» پس از «ماده ۱۰ قانون») فقط تا واژهٔ «قانون» می‌رسد. جزئیات: ADR-0011.

## مثال

```ts
import { buildCorpusIndex } from "@/modules/legal-kb-schema";
import { verifyCitations, checkText, redactRejected } from "@/modules/citation-verifier";

const report = verifyCitations(index, [{ ref: { documentId: "sample-law", article: "2", subpart: null }, quote: "متن ساختگی ماده ۲" }], "2025-03-01");
if (!report.allAccepted) { /* report.rejected[i].code و .message */ }

const check = checkText(index, answerText, "2025-03-01");
const safe = redactRejected(answerText, check); // Result<string>
```

## وقتی چیزی را تغییر می‌دهید
- حکم یا قاعدهٔ تازه: `verify.ts`/`types.ts` + تست + یک جهش در `tooling/mutation/citation-verifier.py`.
- شکل تازهٔ ارجاع در متن: `extract.ts` + تست + ADR (هر شکلِ تازه یعنی ریسکِ پذیرفتنِ نادرست؛ پیش‌فرض: رد).
- قرارداد (`index.ts`) را بدون کار جدا عوض نکنید؛ `ai-orchestrator` به آن تکیه خواهد کرد.
