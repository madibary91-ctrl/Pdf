# tool-call-deadline (لایهٔ ۴ · غیرخالص: تایمر تزریق می‌شود · 🔴 بازبینی انسانیِ اجباری: مالک امنیت) — برش MT-2d

**هدف:** مدتِ هر تماسِ مدل را **سخت** محدود می‌کند تا «گامِ زامبی» (ADR-0065-الف) بر اساسِ ساخت ناممکن شود: تماسی که از `maxCallMs` بگذرد لغو می‌شود و همان لحظه `TIMEOUT` با هزینهٔ **نامعلوم** برمی‌گردد؛ لایهٔ اندازه‌گیری پیش از `graceMs` رزرو را طبق `onUnknownCost` می‌بندد و رفتگر هرگز رزروِ یک تماسِ **زنده** را نمی‌بندد. تصمیم‌ها: `docs/adr/0066-tool-call-deadline.md`.
**وابستگی:** فقط رابط عمومی `ai-gateway` (نوعِ `ToolGateway`/`Timers`). `durable-tool-gateway` را **تغییر نمی‌دهد** (نگهبانِ منبعش تایمر/پرتاب را ممنوع کرده)؛ دروازهٔ ماندگار روی خروجیِ این ماژول ساخته می‌شود.

> ⚠️ هنوز به مسیرِ محصول وصل نیست (`planned`)؛ ریشهٔ I/O (CT‑5c‑2) باید آن را زیرِ دروازهٔ ماندگار بگذارد. بازبینیِ مالک امنیت انجام نشده.

## رابط
```ts
import { createDeadlineToolGateway, checkTimingRelations } from "@/modules/tool-call-deadline";

// ۱) رابطه‌های زمانی را پیش از ساخت بسنجید (ریشه/تنظیماتِ ادمین نباید بتوانند نقضشان کنند)
const issues = checkTimingRelations({ maxCallMs, graceMs, reservationTtlMs });   // [] ⇒ سازگار؛ فقط نامِ فیلد، هرگز مقدار
// ۲) دروازهٔ درونی را بپوشانید و روی آن دروازهٔ ماندگار بسازید
const d = createDeadlineToolGateway({ gateway, maxCallMs /*, timers?, onEvent? */ });   // Result؛ هرگز نمی‌پرتابد
const made = createDurableToolGateway({ ...rest, gateway: d.value, graceMs, reservationTtlMs });
```
## قواعد (خلاصه)
- `maxCallMs`: عدد صحیح ۱ تا ۶۰۰٬۰۰۰، **بی‌پیش‌فرض**؛ `timers` پیش‌فرض ساعتِ سیستم (در آزمون مجازی بدهید).
- رابطه‌ها (`checkTimingRelations`، تنها منبع): هر سه عددِ صحیحِ مثبت؛ `maxCallMs < graceMs`؛ `reservationTtlMs ≥ ۲×graceMs` ⇒ ttl همیشه از زمانِ کلِ یک گام بزرگ‌تر است.
- نتیجهٔ سقف: `{ ok:false, error:{ code:"TIMEOUT", retryable:false, cost:null, usage:null } }` (یخ‌زده، پیامِ ثابت). `TIMEOUT` و `INTERNAL_ERROR` هیچ‌کدام در `NEVER_REACHED_CODES` نیستند ⇒ هزینه «نامعلوم» است، **هرگز «هیچ»** (وگرنه تماسی که شاید پول گرفته رایگان می‌شد).
- سیگنالِ لغو: ترکیبِ لغوِ فراخواننده و سقف به دروازهٔ درونی می‌رسد؛ لغوِ فراخواننده سقف را برنمی‌دارد (دروازه‌ای که لغو را نادیده بگیرد هم از سقف رد نمی‌شود).
- جوابِ دیرهنگامِ تماسِ لغوشده **دورریخته** می‌شود (هرگز رزرو/هزینه را عوض نمی‌کند)؛ فقط رویدادِ بی‌متنِ `late-result` (`ok` و هزینهٔ معتبر) به `onEvent` می‌رسد تا مغایرت‌گیری ممکن باشد. رویدادِ `deadline` هر بار که سقف بزند.
- برپا نشدنِ تایمر ⇒ تماس **شروع نمی‌شود** (`INTERNAL_ERROR`)؛ تماسِ بی‌سقف بدتر از تماسِ انجام‌نشده است. پاک‌سازیِ تایمر همیشه؛ خرابی‌اش نتیجه را عوض نمی‌کند. ناظرِ پرتاب‌کننده بلعیده می‌شود.
- کلیدِ ناشناخته رد می‌شود؛ هر کلید یک بار خوانده می‌شود؛ توابعِ دروازه یک‌بار گرفته می‌شوند؛ هیچ مقدارِ پیکربندی یا متنِ استثنا بازتاب نمی‌شود.

## محدودیت‌های شناخته‌شده (صادقانه)
- **هزینهٔ معلومِ دیرهنگام گم می‌شود:** با `forfeit` کاربر کلِ رزرو را می‌پردازد؛ با `release` پاسخ مجانی است (ADR-0063/0066). کاهشش: `timeoutMs` مدل‌ها در `ai-gateway` را **کمتر** از `maxCallMs` بگذارید تا زمان‌سنجِ خودِ دروازه (که هزینه را گزارش می‌دهد) معمولاً برنده شود؛ سقفِ سخت پشتیبان است. این رابطه را برشِ بعد (سیاستِ آستانه‌ها) ساختاری می‌کند.
- سقف با **تایمرِ فرایند** سنجیده می‌شود و `graceMs` با **ساعتِ دفتر**؛ توقفِ کلِ فرایند/حلقهٔ رویداد (GC طولانی، خوابِ ماشین) یا اختلافِ ساعتِ ماشین‌ها می‌تواند همچنان یک زامبیِ نادر بسازد (کاهش: `graceMs − maxCallMs` را گشاده بگیرید). نتیجهٔ جدا برای «رزروِ بسته‌شده توسط رفتگر» (`LATE_AFTER_CLOSE`) قرارداد `metering` را عوض می‌کند و باز می‌ماند.
- حاشیهٔ `graceMs − maxCallMs` باید زمانِ تسویه (I/Oِ دفتر و outbox پس از سقف) را هم بپوشاند؛ این رابطه فقط `<` را الزام می‌کند و اندازهٔ حاشیه سیاستِ آستانه‌هاست.
- هنوز به مسیرِ محصول وصل نیست.

## آزمون
`config`، `relations` (مرزهای دقیق + ۲۰۰۰ بذر)، `deadline` (رفتاری با تایمرِ مجازی)، `property` (۳۰۰ بذر با داورِ مستقل از روی طرح) و در `tooling/`: `tool-call-deadline-source.test.ts` (نگهبان منبع)، `tool-call-deadline-durable.test.ts` (ترکیب با دروازهٔ ماندگار و رفتگرِ واقعی روی حافظه + شاهدِ کنترلِ بی‌پوشش)، `tool-call-deadline-runtime.pg.test.ts` (PG واقعی + حلقهٔ واقعی + دودیِ زمانِ واقعی با تایمرِ پیش‌فرض).
