# shared-types (لایهٔ ۰)

**هدف:** نوع‌ها و شماهای مشترک بین ماژول‌ها (`JalaliDate`، `GregorianDate`، `Result`، `DomainError`).

**رابط عمومی:** فقط `index.ts` — `ok()`، `err()` و نوع‌ها.

**وابستگی:** هیچ.

**قواعد**
- تغییر اینجا «تغییر قرارداد» است → کار جداگانه + تأیید مالک معماری.
- منطق کسب‌وکار اینجا نباید بیاید؛ فقط شکل داده.
- نوع‌های جدید (پرونده، ماده قانون، …) در گام‌های بعدی و با کار مشخصات جدا افزوده می‌شوند.
