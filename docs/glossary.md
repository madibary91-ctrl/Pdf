# واژه‌نامه

یک اصطلاح، یک معنی؛ در کد و مستندات از همین‌ها استفاده کنید.

| اصطلاح | معنی |
|---|---|
| **ماژول** | پوشه‌ای در `src/modules` با رابط عمومی `index.ts` |
| **رابط عمومی** | آنچه `index.ts` بیرون می‌دهد؛ بقیه داخلی است |
| **لایه** | عدد جهت ساخت (۰ پایین‌ترین) |
| **قرارداد** | نوع‌ها و رابط‌های مشترک؛ تغییر = کار جدا + تأیید معماری |
| **خالص (pure)** | بدون I/O و بدون ساعت/تصادف؛ همان ورودی همان خروجی |
| **برش عمودی** | باریک‌ترین مسیر کامل: پرسش ← پاسخ با استناد معتبر |
| **ناحیهٔ پرریسک** | مسیری که بازبینی انسانی اجباری دارد |
| **نسخهٔ معتبر** | متن یک ماده در تاریخ مشخص (نسخه‌بندی زمانی) |
| **میز کار** | فضای گفتگو و فایل کاربر در وب |
| **مهلت / موعد** | بازهٔ قانونی با تاریخ شروع، واحد و مقدار |
| **روز کاری** | روزی که غیرتعطیل است؛ تعریف از بیرون تزریق می‌شود |
| **نیم‌فاصله (ZWNJ)** | نویسهٔ U+200C |
| **کلید جست‌وجو** | شکل تهاجمیِ نرمال‌شدهٔ متن فقط برای مقایسه |
| **تحویل (handoff)** | یادداشت پایان کار در `docs/handoffs/` |
| **فرض** | سهم معینِ کسری (۱/۲، ۱/۴، ۱/۸، ۲/۳، ۱/۳، ۱/۶) در ارث؛ در برابر «قرابت» که باقیمانده است |
| **قرابت** | ارث‌بردنِ باقیماندهٔ ترکه (بدون سهم معین) |
| **رد** | تقسیم زیادیِ ترکه میان صاحبان فرض به نسبت فرض (جز زوج/زوجه و مادرِ دارای حاجب) |
| **نقص** | کمبود ترکه برای فرض‌ها؛ فقط بر دختر یا دخترها وارد می‌شود |
| **حجب / حاجب** | محروم‌شدنِ کلی یا جزئی وارث به‌سبب وارث دیگر؛ مثلاً برادران، مادر را از ثلث به سدس می‌رسانند |
| **قائم‌مقام** | نوه‌ای که در نبود فرزند بی‌واسطه، جای فرزندِ فوت‌شده را می‌گیرد |
| **ترکهٔ خالص** | ماترک پس از کفن، دیون و وصیت نافذ؛ ورودی موتور ارث |

| **پایگاه دانش (KB)** | مجموعهٔ اسناد حقوقی، مواد و نسخه‌های زمانی، رابطه‌ها و رأی‌ها (`Corpus`) |
| **نسخهٔ زمانی** | متن یک ماده با بازهٔ اعتبار نیم‌باز `[validFrom, validTo)`؛ اعتبار با تاریخ سنجیده می‌شود |
| **شکاف اعتبار** | بازه‌ای که هیچ نسخه‌ای از ماده معتبر نیست (مثلاً میان نسخ و وضع مجدد)؛ جست‌وجو آن را صریح اعلام می‌کند |
| **برچسب متعارف ماده** | شکل یکتا برای ماده: `10`، `10 مکرر`، `10 مکرر 2`، `واحده` (ارقام لاتین) |
| **کلید ارجاع** | رشتهٔ ASCII پایدار برای ارجاع: `سند/ماده[/note|clause/برچسب]` مثل `sample-law/10-bis/note/2` |
| **تأییدشده (verified)** | نسخه‌ای که حقوقدان با نام و تاریخ تأیید کرده؛ فقط همین‌ها قابل استناد به کاربرند |
| **نمونهٔ ساختگی** | داده‌ی آزمایشی بدون ارزش حقوقی (`FICTIONAL_SAMPLE_CORPUS`)؛ هرگز جای قانون واقعی نمی‌نشیند |
| **store (ذخیرهٔ دانش)** | ماژول `legal-kb-store`: ذخیره و پرس‌وجوی `Corpus` در PostgreSQL |
| **دفتر مهاجرت** | جدول `migration_ledger` در همان شِما: نام + checksum هر مهاجرتِ اعمال‌شده |
| **قید نبود هم‌پوشانی** | `EXCLUDE USING gist` روی (سند، ماده، بازهٔ اعتبار) که خودِ پایگاه هم‌پوشانی نسخه‌ها را رد می‌کند |
| **فقط‌افزودنی** | درج که هرگز رکورد موجود را بازنویسی نمی‌کند؛ تکراری = خطا |
| **خودبسنده (Corpus)** | Corpus که همهٔ ارجاع‌های رابطه/رأی‌اش به اسناد خودش است (شرط درج در ۴ب‑۱) |
| **شِمای پستگرس** | فضای نام جدول‌ها (`legal_kb`)؛ جدا از `public` که `drizzle-kit push` مدیریت می‌کند |
| **مسیر اعتماد** | `markVerified` / `revokeVerification` / `correctVersion`: تنها راه مشروع تغییر وضعیت بازبینی یا متن؛ هر کدام با ممیزی |
| **ممیزی (audit)** | جدول فقط‌افزودنی `<schema>_audit.version_audit` با عکس «قبل/بعد» هر تغییر نسخه، کنشگر، تاریخ و دلیل |
| **هش محتوا** | `versionContentHash`: SHA-256 متن و تبصره/بندهای یک نسخه؛ مبنای compare-and-set (کنشگر هشِ متنی را می‌دهد که دیده) |
| **CAS (compare-and-set)** | تغییر فقط اگر وضعیت فعلی همان باشد که کنشگر دیده؛ وگرنه `CONFLICT` |
| **اسکلت زمینه** | شناسه/نوع/عنوان/برچسب مواد/رابطه‌های سندهای موجود که در درج افزایشی با ورودی یک‌جا اعتبارسنجی می‌شود (بدون متن‌ها) |
| **درج افزایشی** | `insertIncremental`: درج فقط‌افزودنیِ Corpus که به اسناد/مواد موجود در پایگاه ارجاع می‌دهد |
