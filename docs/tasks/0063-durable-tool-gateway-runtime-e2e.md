# durable-tool-gateway + settlement-runtime — آزمونِ سرتاسریِ حلقه‌دار روی PostgreSQL

## هدف (یک جمله)
ثابت شود حلقهٔ خودکارِ `settlement-runtime` روی PostgreSQL رزروِ یتیمِ گامِ ابزارِ دروازهٔ ماندگار را (و فقط آن را، فقط پس از مهلت) می‌بندد، با خرابیِ پایگاه نمی‌میرد و بی‌نشت بهبود می‌یابد.

## زمینه
