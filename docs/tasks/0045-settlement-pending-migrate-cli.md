# م۳‑ه‑۴‑الف‑۲‑۴‑ب‑۲‑۱: CLIِ مهاجرتِ نمایهٔ مرده‌های در انتظارِ تأیید

## هدف (یک جمله)
نصب، وضعیت و راستی‌آزماییِ نمایهٔ `settlement-pending` را با یک فرمانِ عملیاتیِ شکست‌بسته (کدهای خروجِ بسته، بی‌نشت، مهلت‌دار) ممکن کند، بی‌تغییرِ `settlement*` و آزمون‌های موجود.

## زمینه
تحویل ۰۰۴۶ («تأیید لازم ۲»، «گام بعد ۱») و ADR-0046؛ مالک سه تصمیمِ معلقِ ۰۰۴۶ را کاملاً به عامل واگذار کرد (ADR-0047 تصمیم ۵). ب‑۲ بزرگ بود و به چهار برش شکسته شد (ADR-0047 جدول).

## ماژول و پوشه‌های مجاز
`src/modules/settlement-pending-migrate/` (ماژولِ تازه)، `src/modules/registry.ts`، `tooling/git-discipline.ts` (فقط `HIGH_RISK_MODULES`)، `tooling/ci-tests.ts` (فقط کفِ شمار)، `tooling/cli/settlement-pending-migrate.ts` (گلو)، `tooling/settlement-pending-migrate-parity.test.ts`، `tooling/mutation/`، `package.json` (فقط اسکریپتِ `settlement:pending`)، `docs/`.

## ممنوع
ویرایشِ هر فایلِ `src/modules/settlement*/**` (بجز ماژولِ تازه)، هر آزمونِ موجود، `shared-types`، `src/app/`، `instrumentation`، وابستگیِ تازه، `vitest.config.ts` برای `ERR_IPC_CHANNEL_CLOSED`، سیم‌کشی به bootstrap (ب‑۲‑۳)، فرمانِ `down` (ب‑۲‑۲).

## قرارداد
`runPendingMigrate({ argv, env, ports: { open, timer, write, createIndex? } })` ⇒ `{ exitCode, report }`، هرگز نمی‌پرتابد. دستورها: `status | up | verify`. کدهای خروج ۰–۱۰ (ADR-0047 تصمیم ۳). `npm run settlement:pending -- <دستور>`.

## معیار پذیرش
1. هیچ آزمونِ موجود و هیچ فایلِ `settlement*` عوض نمی‌شود.
2. `check` پیش از هر نوشتن؛ بی‌کاری = بی‌نوشتن؛ پس از مهلت هیچ migrate تازه‌ای نیست.
3. راستی‌آزماییِ دو‌لایهٔ پس از `up` و بازمحاسبهٔ `consistent`؛ ناهمخوان ⇒ ۹.
4. بازتلاش فقط برای `40P01/40001`؛ `55P03` ⇒ ۱۰ بی‌تکرار.
5. بی‌نشتِ رشتهٔ اتصال/شِما/متنِ خطا؛ آرگومانِ موضعی پژواک نمی‌شود؛ غلط‌یابِ نامِ `SETTLEMENT_*`؛ متغیرهای پایش با همان envِ برنامه پذیرفته.
6. آزمونِ PostgreSQL واقعی (قفلِ مشغول ۱۵ثانیه‌ای، مهلت، سقفِ سمتِ پایگاه، هم‌زمانی) و فرایندِ واقعی (کدِ خروج، SIGTERM).
7. جهشیِ بدونِ زندهٔ توضیح‌نشده؛ دروازهٔ صفر-رد سبز.

## تست‌های مورد انتظار
عادی، مرزی، خطا (نگاشتِ هر کد)، بدجنس (env/argv)، هم‌زمانی، قفلِ واقعی، مهلت/لغو، فرایندِ واقعی، خاصیتیِ تصادفی، همارزی با bootstrap/settlement-migrate، منبع.

## خارج از کار
`down`، سیم‌کشی به bootstrap، `backlog:cost` با منبعِ نمایه، اندازه‌گیریِ زمانِ backfill در مقیاس، رفعِ `settlement-migrate` برای متغیرهای پایش.
