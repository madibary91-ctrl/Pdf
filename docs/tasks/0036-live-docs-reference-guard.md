# tooling م۳‑ه‑۳‑ز: پاک‌سازیِ خانوادهٔ مهاجرتِ تسویه و نگهبانِ راستیِ ارجاع‌های مستنداتِ زنده

## هدف (یک جمله)
اسکریپتِ منسوخِ smoke حذف و سه جملهٔ نادرستِ README اصلاح شود، و آزمونی بسازیم که ارجاعِ مستنداتِ زنده به فایل/پوشه/اسکریپتِ ناموجود را قرمز کند.

## زمینه
تحویل ۰۰۳۷ «گام بعد ۱» (م۳‑ه‑۳‑ز)، ADR-0034 (جایگزینیِ smoke)، ADR-0033، ADR-0038.

## ماژول و پوشه‌های مجاز
`tooling/` (آزمونِ تازه، حذفِ `tooling/smoke/settlement-migrate.ts`، اسکریپتِ جهشیِ تازه، `ci-tests.ts` فقط برای کف)، `docs/` (ADR، task، `known-pitfalls.md`، یادداشتِ تحویل)، و **فقط یک جمله** در README هر یک از `settlement-runtime`، `settlement-host`، `settlement-bootstrap` (سه کامیتِ جدا، G7).

## ممنوع
هر فایلِ غیر-README در `src/`، `registry.ts`، `package.json`، **هر آزمونِ موجود**، ADR/یادداشت/taskِ قدیمی (تاریخچه‌اند)، `tooling/smoke/settlement-next.mjs`.

## قرارداد
بی‌تغییر؛ هیچ رفتارِ زمانِ‌اجرا عوض نمی‌شود.

## معیار پذیرش
1. هر مسیرِ فایل/پوشه در مستنداتِ زنده (AGENTS.md، سه سندِ docs، README ماژول‌ها) موجود است؛ مسیرِ ریشه‌دار دقیق؛ ماژولِ آینده فقط اگر در registry باشد.
2. هر `npm run` در مستنداتِ زنده در `scripts` هست.
3. `tooling/smoke/settlement-migrate.ts` نیست؛ `settlement:migrate` و دودیِ `settlement-next.mjs` هست و از آن استفاده می‌کند.
4. پویشگر با نمونهٔ ساختگی آزموده شده (نقضِ ریشه‌دار، نامِ کوتاه، پوشه، alias، الگو/فرمان، بلوکِ کد، npm run، registry، تکراری) و «تهی‌نبودن» قفل است.
5. سه README جمله‌ای نادرست ندارد (بازبینیِ انسانی با ADR-0038).
6. جهشی: همهٔ جهش‌ها کشته؛ آزمون‌های موجود بی‌تغییر؛ دروازهٔ صفر-رد سبز؛ کف بالا.

## خارج از کار
شِمای ممیزی، یک‌کردنِ کلیدِ قفل، `deliver`ِ واقعی، پایشِ پسماندِ زنگ در `health` (م۳‑ه‑۴: قراردادِ `settlement` را عوض می‌کند و تأییدِ معماری می‌خواهد)، پویشِ ADR/یادداشت‌ها.

## وابستگی‌ها
ADR-0033، ADR-0034، ADR-0037.
