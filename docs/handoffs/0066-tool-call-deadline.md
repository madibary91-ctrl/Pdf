## ۱) چرا این برش (تصمیم من) و چگونه کارِ بزرگ را تقسیم کردم
خواستهٔ شما: CT‑5c‑2 (ریشهٔ I/O با آستانه‌های قابل‌تنظیمِ ادمین و رابطه‌های ساختاری) + رفعِ زامبی. این **بزرگ‌تر از یک برشِ باکیفیت** است؛ تقسیم کردم:
- **MT‑2d (همین تحویل):** رفعِ زامبی. پیش‌نیازِ سخت است: رابطهٔ «`maxCallMs < graceMs`» فقط وقتی معنا دارد که چیزی `maxCallMs` را **اِعمال** کند. بدونِ آن، سیاستِ آستانه‌ها عددی بی‌اثر بود.
- **CT‑5c‑2a (بعد):** ماژولِ خالصِ آستانه‌ها: پیش‌فرض‌های کد (maxSteps، maxToolCalls، maxCallMs، maxCards، model، perMessageOverheadTokens، reservationTtlMs، onUnknownCost، الگوی scopeId) + بازنویسیِ ادمین با اعتبارسنجیِ **ساختاری** که فقط از `checkTimingRelations` (همین برش) و رابطهٔ `model.timeoutMs < maxCallMs` استفاده می‌کند.
- **CT‑5c‑2b:** ذخیره (جدولِ تنظیمات PG) + API ادمین؛ **CT‑5c‑2c:** ریشهٔ I/O (ساخت دروازه/ارائه‌دهنده، `process.env`، سیم‌کشیِ `durable(deadline(gateway))`، رفتگر).
مقدارِ آستانه‌ها را **در این برش ننوشتم** (حدسِ عدد در ماژولِ پول بدونِ برشِ سیاست = بدهیِ پنهان؛ پیشنهادِ اولیه‌ام برای 2a: `maxCallMs ≈ ۴۰٪ graceMs`، `graceMs` ≥ ۳۰ ثانیه، `ttl = ۴×graceMs`، `onUnknownCost: forfeit`؛ در 2a با دلیل و آزمون می‌آید).
**سازمان‌دهیِ نوبت:** کلون و خواندنِ ۰۰۶۵/ADR/کد ← تگ ← **کشفِ مانع** (نگهبانِ منبعِ `durable-tool-gateway` تایمر/`throw`/فایلِ تازه/وابستگیِ `ai-gateway` را ممنوع می‌کند؛ پیش‌نویسِ اولِ من داخلِ آن ماژول بود و ۶ آزمونِ موجود را قرمز کرد ⇒ **کنار گذاشتم و ماژولِ جدا ساختم**، نه تغییرِ آزمون) ← ماژول + آزمون‌ها ← **جهش‌آزمایی (۱۴ جهش)** ← ۲ اجرای پیاپی + ۳ موازیِ آزمونِ PG ← مستند ← `tsc`/`eslint` ← **دروازهٔ کاملِ صفر-رد یک بار** ← کف ← کامیت ← پچ ← دروازهٔ کاملِ دوم روی کلونِ تازه.

## ۴) یافته‌های واقعی
1. **نگهبانِ منبعِ `durable-tool-gateway` مرزِ معماری است، نه مانع:** منطقِ زمان/تایمر نباید به ماژولِ پول برود. ماژولِ جدا + ترکیبِ `durable(deadline(gateway))` درست‌تر است و هیچ آزمونی را تغییر نمی‌دهد. توصیه: ریشهٔ I/O (2c) تنها جایی باشد که این ترکیب ساخته می‌شود؛ ساختنِ دروازهٔ ماندگار بدونِ پوشش هنوز ممکن است (تعمداً؛ ADR‑0066 بند ۲).
2. **`null < ۴۰۰۰` در JS درست است:** باگِ داورِ خودِ من در آزمون (تأخیرِ «هرگز» با `null`) — با `Infinity` اصلاح شد؛ نمونه‌ای از اینکه داورِ مستقل هم باید خودش آزموده شود.
3. **ژورنالِ دفتر برای گامِ درمهلت هم یک `release` (باقیمانده) دارد** — شمردنِ «رکوردِ پایانیِ هر رزرو» باید بر پایهٔ `reservationId` باشد (آزمونِ PG همین را می‌سنجد).
4. **جهش‌آزمایی (۱۴ جهشِ یکتا روی کدِ تولیدی، همه کشته‌شده، سپس بازگردانی):** سقف+۱؛ بی‌لغوِ تماس؛ کدِ «پیش از ارائه‌دهنده» برای سقف؛ بی‌پاک‌سازیِ تایمر؛ `late-result` همیشه؛ مرزِ `>=`→`>` در رابطه؛ ttl `۲×graceMs`→`graceMs`؛ بی‌انتشارِ لغوِ فراخواننده؛ کدِ پرتاب `TIMEOUT`؛ پرتابِ خطای تایمر؛ نشتِ شنونده؛ حدِ پایینِ ۰؛ `retryable:true`؛ بی‌مسابقه. **هیچ بازمانده‌ای نیست.**
5. **قطعیت:** آزمونِ PG: ۲ اجرای پیاپی + ۳ موازی همه سبز؛ هیچ `sleep`ِ ثابت برای درستی نیست (فقط `until` با شرط)؛ تنها انتظارِ واقعیِ ثابت در دودیِ زمانِ واقعی است که ذاتاً برای «رفتارِ منفی» لازم است.
6. **ابزاری:** `npm i --no-package-lock` (بی‌pnpm)؛ `package-lock.json` کامیت نشد. `git config user.*` محلی.

2. **مرزِ اعتبار (قاعدهٔ ۷):** هیچ قیمت/عددِ حقوقی ننوشتم؛ فقط `CALL_DEADLINE_LIMITS` (۱ تا ۶۰۰٬۰۰۰ میلی‌ثانیه، هم‌راستا با سقفِ `ai-gateway`) که کرانِ فنی است نه آستانهٔ محصول. مقدارهای `4000`/`300`/`10_000` فقط در آزمون و ساختگی‌اند.
3. **محدودیت‌های صادقانه:** (الف) **هزینهٔ معلومِ دیرهنگام گم می‌شود** (`forfeit`: کاربر کلِ رزرو؛ `release`: رایگان)؛ کاهش: `timeoutMs`ِ مدل‌ها < `maxCallMs` — در 2a ساختاری می‌شود. (ب) سقف با تایمرِ فرایند و `graceMs` با ساعتِ دفتر سنجیده می‌شود؛ توقفِ فرایند/حلقهٔ رویداد یا اختلافِ ساعت می‌تواند زامبیِ **نادر** بسازد؛ `LATE_AFTER_CLOSE` (قراردادِ `metering`) باز می‌ماند. (ج) `<` تنها الزام است؛ اندازهٔ حاشیهٔ `graceMs − maxCallMs` برای زمانِ تسویه سیاستِ 2a است. (د) به مسیرِ محصول وصل نیست؛ بازبینیِ مالک امنیت انجام نشده. (هـ) دو دودیِ زمانِ واقعی ریسکِ ذاتیِ ناپایداری دارند؛ اگر CI لینوکس ناپایدار دید **اول** آن‌ها (و دو دودیِ ۰۰۶۵) را بنگرید.
4. موارد بازِ ۰۰۴۶–۰۰۶۵ و تصمیم‌های معلق **دست‌نخورده**؛ «الف»ِ ۰۰۶۵ اکنون با ترکیبِ درست **بسته** است ولی در کدِ بی‌پوشش باز می‌ماند. هوک‌های گیت نصب نشد؛ `check-range` دستی گرفته شد.
