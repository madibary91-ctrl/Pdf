# یادداشت تحویل ۰۰۰۸ — CI خودکار و دروازهٔ صفر-رد (بازبینی معماری پس از ۴ب‑۲)

## چه شد
دو ایرادِ بازبینی معماری بسته شد: (۱) نبودِ CI، (۲) رد‌شدنِ ۱۵۶ تست پایگاه در محیط بدون پایگاه.

| | پیش از این کار | پس از این کار (CI) |
|---|---|---|
| اجرای خودکار با push/PR | ❌ | ✅ `.github/workflows/ci.yml` |
| تست‌های پایگاه | ۱۵۶ رد‌شده (بی‌صدا) | **۰ رد‌شده**، روی PostgreSQL 15 واقعی |
| سبز | ۴۴۷ | **۶۰۳ قبلی + ۱۲ تست تازهٔ دروازه = ۶۱۵** (+۱۶ `todo`) |
| «سبزِ بی‌اجرا» ممکن؟ | بله | **نه**: هر skip/شکست/کاهش شمار ⇒ قرمز |

- **تست‌های قبلی دست‌نخورده‌اند:** هیچ `*.test.ts`ِ موجود و هیچ کد منبع (`src/`) تغییر نکرد (`git diff` روی آن‌ها خالی). فقط فایل‌های تازه + `.gitignore` + قفل‌فایل (پایین).
- فایل‌های تازه: `.github/workflows/ci.yml`، `tooling/ci-tests.ts`، `tooling/ci-tests.test.ts`، `docs/adr/0006-…`، همین یادداشت.
- **یافتهٔ ضمنی مهم:** `pnpm-lock.yaml` همهٔ ۵۹۱ بستهٔ خود را از آینهٔ Liara می‌خواند (در CI گیت‌هاب ممکن بود نصب شکست بخورد). `tarball:`ها حذف شد؛ `integrity` و نسخه‌ها دست‌نخورده.
- `.gitignore`: BOM ابتدای فایل برداشته شد (الگوی `node_modules/` را خراب می‌کرد) و `test-results/`، `next-env.d.ts`، `*.tsbuildinfo` افزوده شد. (`.env*` همچنان ایگنور است؛ هیچ رازی در مخزن نیست.)

## چگونه راستی‌آزمایی شد
۱. بازتولید: بدون پایگاه ⇒ `447 passed | 156 skipped | 16 todo`؛ با پایگاه ⇒ `603 passed | 16 todo`.
۲. شبیه‌سازی کاملِ CI روی **کلونِ تازه**: `pnpm install --frozen-lockfile` ← `tsc` ← `eslint` ← کنترل منفی ← دروازه (**۶۱۵ سبز، ۰ رد، ۰ شکست**) ← `build`: همه سبز.
۳. دروازه بدون پایگاه ⇒ کد خروج ۱؛ با پایگاهِ غیرقابل‌دسترس ⇒ کد خروج ۱؛ گزارش واقعیِ «۱۵۶ رد» ⇒ قرمز (تست خودکار + اجرای دستی).
۴. نکته: اجرای واقعیِ GitHub Actions فقط پس از push روی ریپو دیده می‌شود؛ شبیه‌سازی بالا همان دستورهاست ولی خودِ runner را شامل نمی‌شود.

## سؤال/کار باز برای مالک
- در GitHub: `verify` را در Branch protection «الزامی» کنید تا ادغامِ قرمز ممکن نباشد.
- ۱۶ `todo` همچنان منتظر نمونه‌های مرجع حقوقدان است (دروازه آن‌ها را رد‌شده نمی‌داند). اگر بخواهید سقفی برایشان تعیین شود (CI با افزایش todo قرمز شود)، تصمیم شما.
- ۴ب‑۳ (جست‌وجوی کلمه‌ای) همچنان نیازمند تأیید تغییر `dependsOn` در `registry.ts` است؛ ۴ج منتظر حقوقدان. در این کار دست نخوردند.
