## ۴) یافته‌های واقعیِ این برش
1. **باگِ واقعی را آزمونِ خودم گرفت:** اولین پیاده‌سازیِ `observe` پیامِ بومیِ `JSON.stringify` را عبور می‌داد (برای نتیجهٔ چرخه‌دار: «property 'self' closes the circle» — نامِ فیلد/دادهٔ پرونده در پیام). اصلاح: کلِ ساخت در `try { } catch { throw new Error(CONST) }`؛ آزمونِ منبع `.message`، `catch (e)` و هر `throw` غیرِ `new Error(CONST)` را ممنوع و شمارِ `try` را در هر فایل قفل می‌کند.
2. **جهش‌آزمایی:** ۳۷ جهش (اسکریپتِ یک‌بارمصرف، در مخزن نیست): تک‌نشانه‌کردنِ `isPending`، حذفِ بازبین/تاریخ، حذفِ یخ‌زدگی/کپیِ JSON، حذفِ اعتبارسنجی‌ها، سقفِ `>` به‌جای `>=`، حذفِ تکراری‌یابی، حذفِ `CARD_MISSING`/`TOOL_MISMATCH`/`DUPLICATE`، حذفِ هر یک از سه جزءِ `reviewPending`، حذفِ ارتقای کارت، حذفِ فیلترِ اجرای ناموفق، `droppedCards` ثابت، اعلان‌ها، یخ‌زدگیِ خروجی، سقفِ ۱۰ مشکل، اعتبارسنجیِ هر فیلدِ گزارش، برچسبِ «تأییدنشده»↔«تأییدشده». **دو جهشِ اول زنده ماند** (`!Array.isArray(toolRuns)`: فقط `issues` عوض می‌شد؛ و واژهٔ برچسب: آزمون‌ها ثابتِ import‌شده را می‌سنجیدند)؛ دو آزمونِ لفظی افزوده شد ⇒ **هر ۳۷ کشته شد؛ بازمانده صفر.**
3. **نکتهٔ طراحیِ آشکار:** `CARD_MISSING` یعنی مصرف‌کننده باید پاسخِ مدل را **نشان ندهد**؛ این عمداً سخت‌گیرانه است (ADR-0060 بند ۶) و هزینه‌اش «کاربر پاسخ نمی‌بیند» است، نه «پاسخ بی‌هشدار».
4. `ComposedAnswer` عمداً هزینه (`spend`) ندارد؛ آن برای `metering` است. README ماژول `calc-tools` («آداپتور… هنوز نیست») بی‌تغییر ماند (G7)؛ در برشِ ریشهٔ ترکیب به‌روز می‌شود.
